# StudyPython

Python 기초 문법을 아는 상태에서 출발해, **초급 소프트웨어 아키텍트**에게 필요한 기초(데이터 · 아키텍처 · 보안과 신뢰성 · 운영)와
코딩 에이전트 활용, AI 기본 요소, "무엇을 만들지 정하기"까지를 **9단계 54단원**으로 쌓아 가는 학습 저장소입니다.

- 학습 노트: [Andrew Ng: 코딩은 더 이상 병목이 아니다 — 초급 아키텍트 학습 노트](https://claude.ai/artifact/TYZGvjwyDU6SfNaraeA1vp)
  — 이 과정이 무엇을, 왜 다루는지의 근거. 노트의 "학습 로드맵" 표에서 단계별 진도를 관리합니다.
- 전체 지도: [`docs/curriculum.md`](docs/curriculum.md) — 단계·단원·핵심 개념·노트와의 연결
- 공통 명세: [`docs/project-api.md`](docs/project-api.md) — 54단원 동안 키우는 "할 일 관리" 프로그램의 단계별 모습

## 이 과정의 생각

시간표가 아니라 **지도**입니다. 한 단원에 사흘이 걸려도, 삼 주가 걸려도 됩니다. 대신 빠뜨리지 않습니다.

1. **하나의 프로그램을 끝까지 키웁니다.** 03단원의 함수 다섯 개가 메모리 → 클래스 → 파일 → SQLite → 계층 분리 → HTTP API →
   인증·캐시·비동기 → 서비스 분리 → 신뢰성 장치 → 관측·배포·확장 → 에이전트가 호출하는 시스템 → LLM 기능 → 사용자가 원하는 기능으로 자랍니다.
2. **새 개념은 한 번에 2~3개.** 시작 코드와 테스트에 쓰인 것은 그 단원이나 앞 단원에서 설명합니다.
3. **먼저 내 답, 그다음 AI.** 모든 단원에 "스스로 답해 볼 질문"이 있고, `CLAUDE.md`의 **튜터 모드**가 Claude에게 정답 대신 힌트를 주게 합니다.
   노트가 경고한 "챗봇 의존의 함정"을 피하는 장치입니다. 정답이 꼭 필요하면 "정답 코드 보여줘"라고 하세요.
4. **결정은 기록합니다.** 설계 선택이 있는 단원은 `docs/adr/`에 결정 기록(ADR)을 남깁니다. 템플릿: [`docs/adr/0000-template.md`](docs/adr/0000-template.md)

06단원부터는 폴더 안에 **앞 단원까지의 완성본** `todo/` 패키지가 들어 있어, 막혀도 다음 단원으로 갈 수 있습니다.

## 실행

```bash
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt

pytest units/03-functions          # 단원별로 실행합니다 (전체 한 번에 실행은 지원하지 않음)
cd units/06-package-and-cli && python -m todo --help
```

처음에는 테스트가 실패하는 것이 정상입니다. `TODO`를 채워 모두 통과시키는 것이 그 단원의 목표입니다.
단원마다 필요한 추가 패키지(17단원부터 `fastapi` 등)는 그 단원 README에 적혀 있습니다.

## 한 단원을 마치는 기준

각 단원 README의 "완료 기준"을 따릅니다. 공통으로는:

1. 그 단원 테스트가 모두 통과한다.
2. `NOTES.md`에 "스스로 답해 볼 질문"의 내 답과, 배운 것 3가지 / 헷갈린 것 1가지 / 다음 단원에 바꿀 것을 적었다.
3. 설계 선택이 있었다면 ADR을 남겼다 (07단원부터).
4. 브랜치 → PR → 셀프 리뷰 → 머지로 마무리했다 (01단원부터).
5. 학습 노트의 로드맵 표에서 해당 단계의 상태를 갱신했다.

반복하는 의식의 전체 목록은 [`docs/curriculum.md`](docs/curriculum.md)의 "모든 단원에서 반복하는 의식"을 보세요.
