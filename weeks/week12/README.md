# 12주차 — 코딩 에이전트 활용 · 사용자 인터뷰

## 목표

11주 동안 쌓은 기초로 코딩 에이전트를 이끌어 봅니다. 노트의 "실천 체크리스트"를 그대로 따라 기능 하나를 맡기고,
"무엇을 만들지"를 사용자에게서 찾는 연습을 합니다.

## 과제

1. **사용자 인터뷰**: 이 할 일 앱을 2~3명에게 보여 주고 "가장 불편한 점"을 물어 기록
2. **스펙 작성**: 인터뷰에서 고른 기능 하나의 스펙 — 누가 얼마나 쓰는가 / 지연·비용·일관성 중 우선순위 /
   되돌리기 어려운 결정 (노트의 세 줄 질문)
3. **컨텍스트 파일 갱신**: `CLAUDE.md` 에 아키텍처 가정, 데이터 접근 패턴, 테스트 실행법 추가
   (이 주에는 튜터 모드를 끄고 구현을 맡깁니다)
4. **에이전트에게 맡기기**: 노트의 체크리스트(맡기기 전·중·후)를 `NOTES.md` 에 복사해 하나씩 체크
5. **검토**: 에이전트가 만든 코드에 "왜?"를 묻고, 결정 하나를 ADR로 남기기

## 회고 (12주 마무리)

- 1주차 코드와 지금 코드를 나란히 놓고, 가장 크게 바뀐 판단 3가지
- 노트의 5영역 중 가장 약하다고 느끼는 곳 → 다음 12주의 주제
