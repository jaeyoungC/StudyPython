# 11주차 — 로그 · 지표 · CI

## 목표

노트의 질문 "장애를 누가, 무엇으로 가장 먼저 알아채는가?"에 답하고, 테스트를 자동으로 돌립니다.

## 공부할 개념

- `logging` 모듈: 레벨, 구조화 로그(JSON), 요청 id로 로그 묶기
- 지표: 요청 수, 오류율, 응답 시간(p50/p95)
- CI: GitHub Actions에서 push마다 테스트 실행
- 코드 리뷰와 의존성 관리: `requirements.txt` 버전 고정

## 과제

1. API에 요청 로그 미들웨어 추가: 메서드, 경로, 상태 코드, 걸린 시간, 요청 id
2. `/metrics` 엔드포인트로 간단한 카운터 노출
3. `.github/workflows/test.yml` 작성: Python 설치 → 의존성 설치 → `pytest`
4. 일부러 테스트를 깨뜨린 PR을 만들어 CI가 막는지 확인 (확인 후 되돌리기)
