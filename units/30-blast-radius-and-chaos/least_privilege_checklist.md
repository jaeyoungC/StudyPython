# 최소 권한(least privilege) 점검표

"이 주체가 할 수 있는 가장 나쁜 일은 무엇인가?" 를 주체마다 묻고, 그 답이 "운영 데이터 전부 삭제"라면 권한을 줄인다.

| 주체 | 지금 가진 권한 | 실제로 필요한 권한 | 할 수 있는 가장 나쁜 일 | 조치 | 완료 |
| --- | --- | --- | --- | --- | --- |
| todo API 프로세스 → DB | | 읽기·쓰기 (DROP 불필요) | | | [ ] |
| 워커 프로세스 → DB | | tasks 읽기, 알림 큐 읽기·쓰기 | | | [ ] |
| notifier 서비스 → DB | | **없음** (HTTP 로만 받는다) | | | [ ] |
| 보고서·분석 스크립트 → DB | | 읽기 전용 | | | [ ] |
| 코딩 에이전트 → 저장소·파일 | | 작업 브랜치 쓰기, 운영 DB 접근 없음 | | | [ ] |
| 코딩 에이전트 → 셸 명령 | | 테스트 실행. `rm -rf`, `DROP`, 운영 배포 불가 | | | [ ] |
| CI(34단원) → 저장소 | | 읽기 + 상태 보고 | | | [ ] |
| 배포 계정(35단원) → 호스팅 | | 배포만, 결제·삭제 권한 없음 | | | [ ] |
| 나(개발자) 의 평소 계정 | | 운영 DB 쓰기 권한은 **평소에는 없음** | | | [ ] |
